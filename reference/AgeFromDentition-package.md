# AgeFromDentition: Estimate Dental Age

Estimate dental age given a set of dental scores for six teeth following
the method of Šešelj M, Sherwood RJ, Konigsberg LW. 2019. Timing of
Development of the Permanent Mandibular Dentition: New Reference Values
from the Fels Longitudinal Study. Anat Rec 302:1733-1753.
