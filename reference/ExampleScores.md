# Example dental scores

A dataset containing five example dental scores for use in calculating
dental age.

## Usage

``` r
ExampleScores
```

## Format

A data frame with 5 rows and 8 variables:

- ID:

  individual ID

- Sex:

  character of sex: "F" or "M"

- Canine:

  character score for canine

- P3:

  character score for P3

- P4:

  character score for P4

- M1:

  character score for M1

- M2:

  character score for M2

- M3:

  character score for M3
